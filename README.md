# Brazilian E-Commerce Analytics

## Project Overview
An end-to-end Data Analytics portfolio project using the Olist Brazilian E-Commerce Public Dataset.

## Business Objective
Analyze marketplace sales performance, customer purchasing behavior, order fulfillment, and customer satisfaction to derive actionable business insights.

## Tech Stack
- Python (Pandas, NumPy)
- PostgreSQL
- SQL
- Power BI
- Git & GitHub

## Project Status
Sprint 1 — Business Understanding & Data Audit

## Project Structure
- `data/` — Raw and processed data (excluded from Git)
- `notebooks/` — Python analysis
- `sql/` — SQL scripts
- `powerbi/` — Power BI report
- `docs/` — Project documentation

## Dataset
Olist Brazilian E-Commerce Public Dataset.

Dataset source, attribution, and applicable license terms will be documented before publication.

## Key Business Questions
1. How are orders and sales evolving?
2. What is the customer repeat purchase rate?
3. How often are orders delivered late?
4. How does delivery performance relate to review scores?
5. Which categories and regions need operational attention?

## Disclaimer
This is a historical dataset analysis. Findings should not be interpreted as current marketplace performance.
